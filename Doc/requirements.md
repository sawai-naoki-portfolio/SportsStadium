# 企画・要件定義書 — スポーツスタジアム

## 1. 企画の概要

**バスケットボール・テニス・バレーボールの 3 種目を、スマホの横画面で手軽に遊べる 3D スポーツゲーム。** 1 試合数分で遊べ、難易度と試合の長さを選んで CPU と対戦します。

| 項目 | 内容 |
|---|---|
| ジャンル | 3D スポーツ（対 CPU） |
| プラットフォーム | Android / iOS（横画面）、Windows |
| 操作 | タッチ（フローティングスティック＋ボタン）、キーボード、ゲームパッド |
| 1 試合の長さ | 数分（11 点先取・1 セット 3 ゲームなどから選択） |
| 特徴 | コート・キャラクター・テクスチャ・効果音・BGM をすべて実行時に生成（外部アセットは日本語フォントのみ） |

## 2. 種目と形式

| 種目 | 形式 | 主な要素 |
|---|---|---|
| バスケットボール | 1on1 ハーフコート | ドリブル、ジャンプシュート（タイミングゲージ）、レイアップ／ダンク、クロスオーバー、スティール、ブロック、リバウンド、ショットクロック 12 秒、2 点／3 点 |
| テニス | シングルス | トップスピン／スライス／ロブ／ボレー／スマッシュ、サーブ（トス → タイミング）、フォルト／レット、デュース、タイブレーク、セット |
| バレーボール | ビーチ 2on2 | レシーブ → トス → スパイクの連携、ブロック、フェイント、ラリーポイント制、サーブ順の交代 |

## 3. 機能要件

| ID | 機能 | 内容 |
|---|---|---|
| F-01 | 種目選択 | 3 種目のカードと種目ごとの通算戦績 |
| F-02 | 試合設定 | 難易度（3 段階）・試合の長さ（種目ごとに 3 種類）・チームカラー（4 色） |
| F-03 | あそびかた | 種目ごとの操作説明 |
| F-04 | 試合 | 種目ごとのルール・審判・得点・サーブ権・スタッツ |
| F-05 | CPU | 難易度に応じて反応速度・ミス率・攻め方を補間。ボールの先読みで動く |
| F-06 | 演出 | 開始・得点・試合終了のバナー、歓声と観客のアニメーション、紙吹雪、ダンク・スマッシュのスローモーション、振動 |
| F-07 | HUD | スコアボード・ショットクロック・タイミングゲージ・着地点マーカー・ヒント・状況で変わるアクションボタン |
| F-08 | ポーズ | 試合に戻る・最初からやり直す・種目選択へ。バックグラウンドへ回ると自動でポーズ |
| F-09 | リザルト | 勝敗・スコア・スタッツ・もう一度 |
| F-10 | 設定 | BGM・効果音の音量、振動、画質（高画質／省電力）、移動アシスト、戦績のリセット |
| F-11 | 戦績 | 種目ごとの勝ち数・負け数を保存（人が遊んだ試合だけ） |

## 4. 非機能要件

| 区分 | 要件 | 実現方法 |
|---|---|---|
| 操作性 | 片手の親指でも遊べる | 画面左のどこでも出るフローティングスティック、右下に大きなボタン、移動アシスト |
| 操作性 | 入力方式の違いを吸収する | タッチ・キーボード・ゲームパッドを `GameInput` で統合 |
| 性能 | 端末に合わせて負荷を下げられる | 「省電力」で影・観客・パーティクル・ポストエフェクトを抑える |
| 性能 | 処理落ちでボールがすり抜けない | 1 フレームの時間に上限、物理のサブステップ |
| 正確さ | ボールの動きが計算どおり | 重力を解析解で積分する自前の物理。成功判定のシュートが物理的にも入ることをテスト |
| 容量 | アプリを小さく保つ | 画像・音声・モデルを持たず、実行時に生成 |
| 保守性 | 種目を同じ構成で作る | 寸法・得点・審判・打球・操作・表示・調整値・進行に分け、`MatchBase` で共通化 |
| 保守性 | 調整しやすい | 調整値を Inspector に出し、（かんたん, むずかしい）の 2 値から補間 |
| 品質 | 最後まで遊べることを自動で確認 | PlayMode テストで 3 種目を最後まで自動対戦させる |
| 堅牢性 | 壊れた保存値で落ちない | `PlayerPrefs` の値を読み込み時に検証し、範囲外は既定値へ |
